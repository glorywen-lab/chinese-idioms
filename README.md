# 國中文言成語挑戰殿堂 · 全套成語檢測系統

> **設計者**：壽山國中 鄭汶瑜 老師  
> **線上測驗網址 (GitHub Pages)**：https://glorywen-lab.github.io/chinese-idioms/

本專案依據教育部《成語典》首頁筆畫索引進行系統化編排，完整收錄國中三年 17 次段考範圍與進階擴充單元，打造專屬國中生的遊戲化成語情境填空檢測殿堂。

---

## 🎯 核心特色

1. **國中三年全範圍完整涵蓋 (20 大單元 · 80 列 · 1,435 則核心成語)**：
   - **七年級**：7上（第1~3次段考）、7下（第1~3次段考）共 6 次段考（第 1～24 列）
   - **八年級**：8上（第1~3次段考）、8下（第1~3次段考）共 6 次段考（第 25～48 列）
   - **九年級**：9上（第1~3次段考）、9下（第1~2次段考，會考衝刺）共 5 次段考（第 49～68 列）
   - **其實還有**：進階高手拔尖卷（一）、（二）、（三）（第 69～80 列）
2. **多句型生活語境題庫（智慧防重複機制）**：
   - 每則成語配備多組相異的生活化與文言情境待答句（全題庫超過 4,300 句待答庫）。
   - 內建未見優先演算法，學生重複作答不會一直遇到相同句子，真正考驗成語理解與語境應用能力。
3. **雙軌測驗與學習架構**：
   - **模式一 · 逐列小單元精熟學習**：以 1 列為單位出題，答對答錯即刻反饋，附成語釋義提示、注音與詳細情境辨析。
   - **模式二 · 段考模擬考隨機抽測**：從大單元中隨機抽取 20 題，全真模擬段考，具備作答計時、答題卡快速跳轉與交卷結算。
4. **專屬錯題消滅戰與錯題本**：
   - 自動將答錯題目集中收錄至錯題筆記本，支援一鍵發動「錯題消滅戰」定點突破。
5. **勳章館成就圖鑑與等級評定**：
   - 依得分評定等級稱號（成語大宗師、翰林學士、詞林進步星、勤學新秀）與專屬鼓勵評語。
   - 42 枚榮譽勳章（各單元滿貫金章、拔萃銀章、錯題清道夫、快思敏捷）。
6. **綠色純前端架構 (Single-file HTML)**：
   - 單一檔案（index.html）即開即用，無需後端伺服器或資料庫。
   - 支援平板、手機、電腦與電子白板，支援離線作答，進度自動儲存於瀏覽器 LocalStorage。

---

## 🚀 部署至 GitHub Pages

1. 將 `index.html` 上傳推送到 GitHub 儲存庫 `glorywen-lab/chinese-idioms`。
2. 進入儲存庫的 **Settings** ➔ **Pages**。
3. 在 **Build and deployment** 下方的 **Branch** 選擇 `main`（或 `master`），資料夾選擇 `/ (root)`，點擊 **Save**。
4. 等待 1~2 分鐘，即可透過 `https://glorywen-lab.github.io/chinese-idioms/` 分享給全校學生使用！
